# Slide 1

![Original slide 1](../../../public/generated/week-01-lecture-02/slide-001.png)

## Explanation

This slide begins the network-component view by distinguishing the devices, software, and connections involved in communication.

## Walkthrough

A **host** is any computer or device connected to a network. A host can run one or more **applications**. An application is software on one host communicating with an application on another host—for example, email or chat on the left communicating with a game or DNS service on the right.

A **server** is a host that provides data or services; a **client** is the host or program requesting that service. These roles describe what a device or program is doing in an interaction, not necessarily a permanent type of hardware.

The blue devices in the middle are routers, which forward traffic between links. A **link** or **channel** connects devices so messages can travel. It may be a cable, optical fibre, or free space for wireless communication. The green arrows illustrate one possible path through several intermediate devices.

## Connections and exam relevance

This slide expands the client/server picture from Lecture 1: applications run on hosts, hosts communicate through links, and intermediate network devices help forward the traffic. These component distinctions are important when tracing encapsulation and packet movement. [week-01-lecture-02, p. 1]
