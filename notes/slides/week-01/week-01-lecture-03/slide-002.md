## Explanation

Client–server architecture describes a communication relationship: a client requests a service, and a server provides it.

## Walkthrough

The diagram shows two client computers on the left sending requests through the network to a server on the right. A server can be a powerful physical computer, but the more precise idea is a **server process**—a program waiting for requests and providing a service. Examples include web servers, FTP servers, and email servers.

The word “client” can likewise refer to the program making the request, not only the whole computer. A single host can run multiple client and server processes at the same time; the roles describe the communication being considered.

## Connections and exam relevance

This refines the earlier client/server examples and provides the architecture that socket programs implement: the client uses a socket to request service, while the server listens for and responds to requests. [week-01-lecture-03, p. 2]
