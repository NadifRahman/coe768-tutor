![Original slide 15](../../../public/generated/week-01-lecture-03/slide-015.png)

## Explanation

Networks provide several important functions and services, including reliable data transfer, error and flow control, routing, and security. The layered design asks where each function belongs and which protocols implement it.

## Walkthrough

The slide highlights four kinds of questions:

1. How many layers are used, and what purpose does each serve?
2. Which function or service and which protocol belong to each layer?
3. Is a function handled by one layer or multiple layers?
4. Which devices implement it—for example, a network card, switch, router, or access point?

For example, routing is primarily associated with routers and the network layer, while a network card and switch participate in local link transmission. Reliability or security may involve more than one layer.

## Connections and exam relevance

This slide previews the kinds of analysis expected when studying a protocol stack: do not memorize only layer names; connect each service to its protocol, implementation, and device.
