# Slide 34

![Original slide 34](../../../public/generated/week-02-lecture-02/slide-034.png)

## Explanation

The application layer provides network services to end users and applications. Examples listed on the slide include HTTP for Web communication, FTP for file transfer, NFS for network file access, email services, VoIP, Secure Shell (SSH), and TELNET. [week-02-lecture-02, p. 34]

## Walkthrough

These examples represent different goals an application may have: retrieving Web resources, transferring files, accessing remote files, communicating by email or voice, or remotely operating another machine. The application layer defines the messages and rules that support those goals; lower layers then carry those messages through the network.

## Connections and exam relevance

Remember the distinction from earlier: a browser or email client is an application, while HTTP or an email protocol is a protocol used to provide the service. SSH and TELNET are both remote-access technologies, but SSH is designed for secure remote access whereas TELNET is an older, insecure protocol. [week-02-lecture-02, p. 34]
